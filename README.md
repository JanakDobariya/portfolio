# Janak Dobariya — portfolio

A lightweight, single-page portfolio built with plain HTML, CSS, and JavaScript. It includes education, skills, languages, selected projects, and contact links without a build step or framework dependency.

## Preview locally

Open `index.html` directly in a browser, or serve the directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

Project cards link to their real GitHub repositories. Update both the description and destination together when changing the featured work.
